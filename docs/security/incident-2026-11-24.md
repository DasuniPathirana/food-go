# Security incident: untrusted Playwright configuration

On 24 November 2026 a static review of the Melbourne branch found an appended, obfuscated remote-code loader in playwright.config.ts. It looked up an external blockchain transaction and executed its decoded input as JavaScript in the local Node process. It is not FoodGo functionality. The root manifest also added an unneeded node-fetch dependency absent from the lockfile, causing npm ci to fail.

The appended loader and unmatched dependency were removed. The lockfile's original root dependencies are unchanged. A narrow static regression test was added. This is containment, not evidence that other code or a previously used workstation is clean.

Do not run the affected local checkout or its test tools. If the config ran, assume credentials accessible to the process may have been exposed. From a trusted device, revoke/rotate GitHub tokens and sessions, deployment credentials, Supabase privileged and database credentials, email/SMS API credentials and any other accessible secrets. Review audit logs, scan the workstation, and use a fresh reviewed checkout on a clean machine. Never paste secrets into chat or commit them. Preserve evidence privately and coordinate with the hosting team and client security contact. Check the other remote and branches for the same injection before trusting them. Do not publicly deploy until independent incident review, clean dependency installation, build and functional checks pass.
