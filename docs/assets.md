Icons use Lucide under its ISC license. The original illustrative SVG map is not geographic data or navigation guidance. The mobile illustrations are original vector artwork.

The optional Foodie, Trailblazer, Sky and Violet avatars use original procedural Three.js geometry and authored SVG fallback illustrations in the repository. They do not use external character models, franchise assets, texture downloads or paid generation services. Three.js is distributed under its MIT licence through the pinned npm dependency.

These paths are relative to `apps/web/public`. Milestone 12 uses the installed Arial/Helvetica sans-serif stack for functional headings, reading and controls; these system fonts are not redistributed in the repository. Bricolage Grotesque remains in the original wordmark. Source Sans 3, Fredoka, Nunito Sans and Outfit assets and licences remain for historical designs. No third-party font request is made. The recent UI refinements add no generated raster images; they reuse the credited local food photography and original vector/map/avatar artwork. Native currently uses the platform font and has not received the complete browser redesign.
