# Food Go project direction

The client approved the standalone `prototype` map behaviour, animations and dimensional presentation. The latest correction on 13 November 2026 explicitly requires a LIGHT theme with bright colours and bold readable fonts. The previous dark theme is superseded. Food Go now also includes a social food experience: public feed, personal walls, thoughts, experience posts, likes, comments and sharing. Read PRODUCT.md and DESIGN.md for the current direction.

For interface work, inspect the relevant `prototype` screens and styles before choosing a new direction. Explore work should also inspect `prototype/map.js` and the running prototype. Preserve the bright immersive illustrated map, layered buildings and shadows, photo markers, explorer and radar, movement and discovery interactions. The map should remain highly interactive and the focal Explore surface. Recommendations, walking controls, selected-place details and mall shop lists expand below the scene so they do not cover it. Group shops sharing a mall into one explicit building marker with a shop count and floor/unit directory. Explore remains the first screen and the centre navigation item, with a prominent Feed tab and Passport for the account and personal wall. Keep food trails reachable even when Feed occupies a primary navigation slot. Carry this direction into the connected web and native experiences; do not replace Explore with a generic list or a small decorative map widget. Keep the original prototype intact unless the user requests changes there.

The approved artwork uses SVG and CSS to create depth. Preserve the appearance and behaviour without implying that the prototype is an accurate geographic map. Connected venue locations, identity, check-ins, ownership approval and rewards require real data and server verification. Prototype simulations are presentation references, not trusted production rules.

Maintain keyboard access, touch controls, reduced-motion support and one main vertical page scroll. Use plain Australian English, no emojis or em dashes in application copy, and the existing icon system.

The owner has explicitly confirmed the Supabase project `Food go` (`azccigsctzhbaxoajqst`) as a development/test target. Approved database fixture tests must roll back their records and temporary grants. Do not reset the hosted database. Brevo configuration is deferred; Mobile Message is intended for SMS sign-in codes. Keep credentials out of source, logs and chat, and keep production account gates closed until their documented requirements pass.

Read `docs/progress/07-bright-community.md` for the latest delivery. Milestone 06's dark palette is superseded. Read `docs/progress/05-approved-map-and-database.md` for earlier database validation and `docs/progress/04-project-analysis.md` for the complete analysis. Nested application instructions also apply, including the installed Next.js documentation requirement.
